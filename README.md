# Кратчайшие пути в неориентированном графе (C++17)

Командный проект для сравнения пяти алгоритмов: **Дейкстра**, **Беллман — Форд**, **Флойд — Уоршелл**, **Левит** и **Джонсон**.

Графы считываются из файлов `.txt` (первая строка: `n m start`, затем `m` строк `u v weight`). Графы неориентированные, веса — неотрицательные целые числа. Все файлы расположены в корне проекта, папок нет.

`main.cpp` читает графы и запускает сравнение. `compare.cpp` вызывает пять алгоритмов, сравнивает результаты и выводит только `ALGO_MS` — время работы самого алгоритма. Каждый алгоритм реализуется в собственном `.cpp`; пока в них стоят заглушки `NOT_IMPLEMENTED`.

Сборка:

```bash
g++ -std=c++17 -O2 main.cpp compare.cpp dijkstra.cpp bellman_ford.cpp floyd_warshall.cpp levit.cpp johnson.cpp -o shortest_paths
```

Запуск: `./shortest_paths` (все тесты) или `./shortest_paths graph_small.txt` (один файл). Подробные инструкции для участников — `TEAM_INSTRUCTIONS.txt`.
